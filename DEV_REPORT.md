# Development Report

Generated from the git history on 2026-05-11. This report intentionally lists only major milestones, not every bug fix, refactor, or documentation update. Timestamps are commit author timestamps from `git log`.

## Executive Summary

The project started as a Solid/Bun research review application backed by Postgres, then grew into a local-first single-user system optimized for large judgment workloads. The largest architecture shifts were the LLM runtime move from vLLM to SGLang, the analytics path through ClickHouse, and the later cutover from Postgres/ClickHouse to SQLite plus DuckDB. The current architecture centers on local SQLite job queues, DuckDB marts, provider adapters, durable judge-worker execution, and desktop/web parity.
