# Review Storage Shape Evidence Unblocker

## Purpose

This follow-up slice turns the static storage-shape audit into smaller, runnable
evidence artifacts without editing `STORAGE_SHAPE_AUDIT_PLAN.md`.

The scope is evidence only. It must not delete, slim, migrate, rewrite, or
retune review-serving storage. Any implementation slice still requires separate
route parity, retention, recovery, benchmark, and live progress proof.

## Goals

1. Collect approved current-DB physical evidence from a read-only DuckDB
   snapshot.
2. Record baseline row, column, timestamp, null, approximate-distinct, JSON size
   proxy, duplicate-key, and index evidence for hot review-serving tables.
3. Preserve the existing route parity and benchmark command boundary in a small
   reviewable file.
4. Keep the large audit result file stable; use new Markdown artifacts for this
   follow-up evidence.
